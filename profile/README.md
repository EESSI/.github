#  European Environment for Scientific Software Installations (EESSI)

Welcome to [EESSI](https://www.eessi.io/)'s GitHub organization! Find our offical documentation [here](https://eessi.io/docs) 📜

The European Environment for Scientific Software Installations (EESSI, pronounced as "easy") is a collaboration between different European partners in HPC community. The goal of this project is to build a common stack of scientific software installations for HPC systems and beyond, including laptops, personal workstations and cloud infrastructure.

We maintain a [list of systems where EESSI is available](https://www.eessi.io/docs/systems/), and [installing EESSI for yourself](https://www.eessi.io/docs/getting_access/is_eessi_accessible/) is well documented. 

Here, you can contribute new software to EESSI or even contribute to the development of EESSI itself. EESSI is organized in three [layers](https://www.eessi.io/docs/overview/), each with a dedicated repository.

Relevant repositores:
- 🆕 [software-layer](https://github.com/EESSI/software-layer) - Go here to for the [software layer](https://www.eessi.io/docs/software_layer/), where you can contribute new software to EESSI
- ⚙️ [compatibility-layer](https://github.com/EESSI/compatibility-layer) - Go here for information and changes to the [compatibility layer](https://www.eessi.io/docs/compatibility_layer/) enabled by Gentoo Prefix
- 🗂️ [filesystem-layer](https://github.com/EESSI/filesystem-layer) - Go here for information and changes to the [filesystem layer](https://www.eessi.io/docs/filesystem_layer/) enabled by CernVM-FS
- 🛠️ [software-layer-scripts](https://github.com/EESSI/software-layer-scripts) - Go here for the tooling and scripts used to build software for the [software layer](https://www.eessi.io/docs/software_layer/)
- 🤖 [eessi-bot-software-layer](https://github.com/EESSI/eessi-bot-software-layer) - Go here for the code powering the EESSI [Build-test-deploy bot](https://www.eessi.io/docs/bot/) used in all EESSI software installations
- 📚 [docs](https://github.com/EESSI/docs) - Go here to suggest changes to our [documentation](https://eessi.io/docs)
- 🔍 [test-suite](https://github.com/EESSI/test-suite) - Go here for the [EESSI ReFrame test suite](https://www.eessi.io/docs/test-suite/).

Thanks to the [MultiXscale](https://www.multixscale.eu/) [EuroHPC](https://www.eurohpc-ju.europa.eu/) Centre of Excellence we are able to provide [support](https://www.eessi.io/docs/support/) to the users of EESSI.

The EESSI support portal is hosted in GitLab: https://gitlab.com/eessi/support.
