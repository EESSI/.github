# Community health files for the EESSI organization

- The `README.md` in the `profile` folder controls the contents of https://github.com/EESSI
- The `SECURITY.md` file is picked up in each repository under the `EESSI` organization (see `Security` tab in the README).

For more information, see https://help.github.com/en/articles/creating-a-default-community-health-file-for-your-organization
